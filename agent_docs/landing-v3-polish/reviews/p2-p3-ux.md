## Summary

- P2 CHANGES. The retimed copy hold and the crossing tiles work inside the pin. The tiles never cover readable copy, the scroll back up is symmetric, and reduced motion and mobile are unaffected. But the wall's exit (1.3 viewports) ends about 0.6 viewport before the tools pin starts (1.9), so the top of the screen sits empty on every desktop visit on /v2 and /v3, in both GL and the DOM fallback.
