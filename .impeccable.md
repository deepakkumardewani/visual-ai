# Impeccable Design Context

## Design Context

### Users

Creators and hobbyists generating AI images (text-to-image). They work in focused sessions — writing prompts, waiting on generations, browsing/curating their output. Viewing context is typically evening/desktop; the dashboard defaults to a dark theme.

### Brand Personality

Warm, crafted, unhurried — an "atelier" rather than a tech console. Three words: **warm, refined, quiet**. The interface should feel like a well-lit studio: the user's images are the artwork; the chrome recedes.

### Aesthetic Direction

- Dark-first warm palette: near-black warm canvas (`--tw-canvas: 9 7 5`), layered warm surfaces, parchment ink (`240 232 220`).
- Accents: copper `#c98a5a` and muted gold `#c9a84c` (see `.eyebrow`, `.gold-glow-bg`). Accents are rare — status dots, hover rings, labels.
- Hairline borders (`--tw-hairline`) over shadows; soft rounded cards (`tw-rounded-card`).
- Motion: exponential ease-out (`cubic-bezier(0.16, 1, 0.3, 1)`), 300–600ms, opacity/transform only, always behind `prefers-reduced-motion`. One well-placed reveal beats many micro-animations.
- Anti-references: neon/cyan SaaS dashboards, glassmorphism, gradient text, busy skeleton shimmers.

### Design Principles

1. **Images are the hero** — UI chrome stays low-contrast; the grid gets the space.
2. **Quiet motion** — animations mark state changes (new content arriving) once; nothing loops loudly or replays on revisit.
3. **Warm neutrals, rare accents** — copper/gold appear only where attention is earned.
4. **Rhythm over uniformity** — tight grouping inside a generation row, generous separation between rows/sections.
5. **Tokens only** — colors from `--tw-*` channels in `style.scss`; spacing from the Tailwind scale; no arbitrary hex or px values in components.
