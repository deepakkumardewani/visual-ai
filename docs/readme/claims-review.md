## BLOCKING

- Line 57: "Most cost 1 credit per image" is false. The split is 10 models at 1 credit and 10 at 5 (`credits.ts:39-72`).
- Line 118: "keeps the latest 100/500" is false. At the cap, new generations are not saved and nothing is evicted (`generation-service.ts:134-145,302-315`).
- Line 199: "validates the body with shared zod schemas" is false. No zod parse on `/generate/image`; validation runs against the registry in the worker (`generate.ts:130-148`, `model-input.ts:85`).
- Line 200: the pipeline order is wrong. The code saves to MongoDB and deducts credits before the Cloudinary upload (`generation-service.ts:299-326`). Fix the text; the diagram is acceptable, but listing the edges in order (Replicate, Mongo, Cloudinary) would match it better.
- Line 206: "a script syncs it against Replicate's OpenAPI schemas" is false. `check-model-docs.mjs` validates the docs and can print schemas; it does not sync anything.

## ADVISORY

- A1: `demo-poster.webp` is not referenced anywhere. If it is meant as the poster for the MP4 or as a static fallback for `demo-teaser.webp`, wire it in. The `#demo-video` link (line 10) points at a placeholder comment until the MP4 is dropped in.
- A2: Line 92 caption "with moderation" suggests the prompt tools are moderated. They are not; only generation prompts are (claim 15).
- A3: Credits are deducted before the Cloudinary upload (`generation-service.ts:300` vs :326). A failed upload leaves the job in `error` with credits already spent, so "only on success" holds only for Replicate success.
- A4: The diagram edge `Redis -->|GET /progress (SSE)| Web` leaves out that the API polls Redis and serves the SSE stream (`generate.ts:74-87`). Consider `Redis --> API -->|SSE| Web`.
- A5: Line 169 "one validation source for web and API": shared zod schemas back feedback, saved prompts and collections, but the generate schemas are unused by the API.
- A6: Line 182 understates Docker. It runs the API (prod and staging) as well as Redis.
- A7: Loose wording that is not false: "live FX" (cached 7 days), "global" shortcuts (studio only), "first session" (account under 12 h), "one model registry" (cost and gating live in separate maps).
