Media studio redesign: design gallery

Ten screens in one shared studio system. Each has its distinctive idea, references, every state at 1440 and 375 in light and dark, a link to the live mockup, and its motion spec. Mockups load tokens from the running dev server.

studio-framemusic-studiosong-studiospeech-studiovideo-studiotool-image-watermarktool-video-watermarktool-autocaptiontool-sketchlibraryREFS.md
Assumptions
  • Existing-screen refs come from the user’s screenshots, which are dark mode only. The running dev app renders blank because packages/shared/dist is stale (isTypingContext export missing), and the designer may not rebuild it.
  • Mockups link the dev server’s compiled token stylesheet (https://visual-ai.localhost/src/style.scss?direct), because the source is SCSS and does not load as a relative file under file://.
  • Gold has no CSS variable, so it is derived from --tw-accent with relative colour syntax. Proposed tokens for builders: --tw-gold, an ease-out-expo easing token, --player-h (76px) and --composer-w (520px).
  • Procedural cover hues are offsets from the copper accent (CSS relative colour), with no new colour tokens. Covers are CSS gradients keyed by a hash of the title.
  • Images have no title field, so image cards show the prompt and offer no rename (R46). Library sample counts (412 / 164 / 28 / 96 / 74 / 50) are illustrative.
  • Video watermark: the tool fixes the mark’s position, so the mockup shows the placement as locked and offers only text and size.
  • Autocaption: the tool exposes no caption style options, so none are offered. The transcript lines are the result surface.
