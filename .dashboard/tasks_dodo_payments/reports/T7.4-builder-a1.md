## Implementation Summary

Razorpay is fully replaced by **Dodo Payments (test mode)** for four INR one-time credit packs. The API exposes a provider-agnostic `PaymentProvider` port with a Dodo adapter (`checkoutSessions.create`, signature-verified webhooks, idempotent credit grant by `payment_id`). The web opens checkout via `dodopayments-checkout` overlay, polls session status, and refetches credits from the API (never client-side increment). Shared catalog lives in `packages/shared`. Automated coverage: Vitest (API payments/webhook paths, web checkout composables), Playwright QA billing specs with stubbed overlay and locally signed webhooks, plus full unit suite green.
